# Planted — Writing & Formatting Style Guide

This guide standardizes formatting + writing style across all uploaded Planted notes.

---

## 1) Page structure (use this order)

1. **Header block** (Week/Vol/Chapter + theme)
2. **Purpose / outcomes** (3 bullets)
3. **Run of show** (timeboxes)
4. **Activity (optional)** (setup → instructions → debrief)
5. **Teaching / framework** (big idea → key points → visual/metaphor)
6. **Scripture study (S.O.A.P.)**
7. **Discussion questions**
8. **Next steps + homework**
9. **Announcements**

---

## 2) Heading conventions

- Use **H2 (`##`)** for major blocks (Welcome, Activity, Scripture, etc.).
- Use **H3 (`###`)** for sub-sections (Debrief, Key points, etc.).
- Avoid all-caps headings.

Recommended top headings:

- `## Session header`
- `## Prep`
- `## Welcome`
- `## Opening prayer`
- `## Recap + homework review`
- `## Activity (optional)`
- `## Teaching / framework`
- `## Scripture study (S.O.A.P.)`
- `## Discussion`
- `## Next steps + homework`
- `## Announcements`

---

## 3) Writing style

**Voice:** warm, clear, invitational; avoid overexplaining.

**Rule of 1:** 1 big idea per session; everything else supports it.

**Paragraphs:** keep most paragraphs 1–4 lines.

**Bullets:**

- Prefer short bullets (one idea per bullet).
- Use numbered lists only for steps.

**Quotes:** use blockquotes only for quotations.

---

## 4) Scripture formatting

Standard format:

- **Passage label**: `**John 1:14**` (bold reference)
- **Text** (optional): include only if needed; otherwise reference only.

For multiple passages:

- `**Primary passage:** ...`
- `**Supporting passages:** ...`
