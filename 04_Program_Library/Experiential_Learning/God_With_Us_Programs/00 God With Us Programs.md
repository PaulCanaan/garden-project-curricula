# God With Us Program Library

Portable experiential programs that help participants recognize, inhabit, and remember the presence-and-homecoming theology of *God With Us*.

## Entrance program

- [[Building A House]] — use ordinary objects to create a recognizable house frame, then learn to see Foundation → Frame → Dwelling and the recurring temple structure throughout Scripture

## Program identity

Programs in this collection should be:

- **simple** — understandable without elaborate explanation;
- **replicable** — usable by trained facilitators in churches, homes, retreats, or classrooms;
- **meaningful** — the experience naturally generates the theological question;
- **memorable** — one embodied metaphor remains after details fade;
- **portable** — minimal materials, preferably resources already present in the room.

**Minimal materials. Maximum meaning.**
